# Finance Advising Planner v4

This version uses one three-state checklist for all requirements:

1. Not taken
2. In progress
3. Completed

Click a course card to cycle its status. The planner preserves selections in browser storage and uses completed plus in-progress coursework to build future-semester recommendations.

## Deploy

Upload `index.html` and `.nojekyll` to the repository root, replacing the existing `index.html`. Keep GitHub Pages set to `main` and `/ (root)`.
